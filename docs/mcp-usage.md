## Reading this

- **Big results** and **chains** are where a codemode wrapper helps: a script reads the large result and returns only what you need, and a chain of calls becomes one script.
- A service with many calls but small results and no chains (for example a lookup tool) gains little: the saving there is only the smaller tool definition.
- Servers with an opaque id are matched to a service by their tool names (`BY_TOOL` in `scripts/mcp-usage.ts`); an unmatched server is listed under its own name.
